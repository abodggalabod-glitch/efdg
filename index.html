🐍 محطة لغة بايثون (Python) - البرمجة السهلة والقوية

تعتبر لغة بايثون الخيار الأول لمطوري الألعاب والمبرمجين المبتدئين نظراً لسهولة قراءتها وكتابتها. إليك كود متقدم قليلاً يمثل نظام حساب نقاط اللاعب والتحقق من مستواه:

# برنامج نظام مستويات اللاعب في بايثون
def check_player_level(score):
    if score >= 1000:
        return "مستوى محترف (Pro Gamer)"
    elif score >= 500:
        return "مستوى متقدم (Advanced)"
    else:
        return "مستوى مبتدئ (Beginner)"

# تجربة النظام
player_name = "عبد الرحمن"
player_score = 750

print(f"أهلاً بك يا {player_name}!")
level_status = check_player_level(player_score)
print(f"حالتك الحالية: {level_status}")
💡 مفهوم برمجي: نستخدم الكلمة المفتاحية def لإنشاء دالة (Function) تقوم بتنفيذ مهمة محددة وإرجاع النتيجة، مما يجعل الكود منظماً وقابلاً لإعادة الاستخدام.

⚙️️ محطة لغة سي بلس بلس (C++) - قوة الأداء وسرعة الألعاب

تُعد لغة C++ العصب الرئيسي لأضخم ألعاب الكمبيوتر (مثل محركات الألعاب الكبرى) لأنها تتحكم بالذاكرة مباشرة وتمنح أداءً خارقاً. إليك كود يعرض إدارة طاقة السلاح وعدد الطلقات:

#include <iostream>
using namespace std;

class Weapon {
public:
    string name;
    int ammo;

    // دالة لتجهيز السلاح
    void shoot() {
        if (ammo > 0) {
            ammo--;
            cout << "تم إطلاق رصاصة! الطلقات المتبقية: " << ammo << endl;
        } else {
            cout << "نفذت الرصاصات! قم بإعادة التعبئة (Reload)." << endl;
        }
    }
};

int main() {
    Weapon rifle;
    rifle.name = "قناص هجومي";
    rifle.ammo = 3;

    cout << "السلاح الحالي: " << rifle.name << endl;
    rifle.shoot();
    rifle.shoot();
    rifle.shoot();
    rifle.shoot(); // هنا ستنفذ الطلقات
    
    return 0;
}
💡 مفهوم برمجي: في لغة C++ نستعمل نظام البرمجة كائنية التوجه (OOP) عبر بناء `Class` لتمثيل كائنات اللعبة مثل الأسلحة واللاعبين بمرونة عالية جداً.
